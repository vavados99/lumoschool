## Ручки и тесты
- Экспорт: `GET /api/export/:id` (S 16+ и P — свои/ребёнка; O — только с правом `data.export_any`, по умолчанию его нет — `consent.test.ts:162`; ребёнок до 16 сам — нельзя, `:123`).
- Согласия: `GET/POST /api/consents/:id`, `POST /api/consents/:id/revoke` (`consent.test.ts:30`, `:64`, `:85`).
- **Стирание (Ф25): `POST /api/erase/:id`, тело `{"confirm":true}`.** Владелец — любого ученика или родителя; родитель — себя или своего ребёнка до 18; ученик и преподаватель — 403 (ученик 16+ просит владельца — ограничение, сделано намеренно минимально); преподавателя и владельца стереть нельзя (403), чужого ребёнка — 403. Ядро — `eraseData` (`data.erase`/`data.erase_any`). Сверх прежнего: стираются реплики человека в чате урока; ссылки на него в `audit_log` обезличиваются (id → 0); действие пишется в журнал (`data.erased`). Связи родитель—ребёнок удаляются (в обезличенном виде не хранятся: по ним можно восстановить, чей это ребёнок); согласия остаются отозванными как доказательство до `retain_until`. Тесты: `test/f25-erasure.test.ts`. **Не сделано:** канал приёма просьбы, проверка личности просящего, срок ответа (1 месяц) — владелец выполняет вручную; резервные копии стирание не затрагивает, но при `restore` стёртые обезличиваются повторно (Ф26, `erased_subjects`; проверено живым процессом 20.10.2026: старая копия → `npm run restore` → «re-erased after restore: 1», имя снова «Deleted user»). Если стирает себя родитель, связи с детьми удаляются, согласия по ним отзываются, будущие записи детей снимаются — дети остаются без привязанного родителя. Вход стёртого невозможен сразу.
- Чистка: `runRetention` (право `retention.run`, только O) — по таймеру планировщика (`cleanupOnce` в `scheduler.ts`, умолчание раз в час, `SCHEDULER_CLEANUP_MS`) или `npm run maintenance`; тесты `consent.test.ts:229`, `:247`.
- **Сроки Ф25 (чат урока 90 дн., журнал 365 дн.) — мои предложения, юристом не согласованы.** Настройка: `CHAT_RETENTION_DAYS` (≥1), `AUDIT_RETENTION_DAYS` (≥30); тот же планировщик и `npm run maintenance`; тест `f25-erasure.test.ts` (старые строки уходят, свежие и граница остаются).
- **Порог 16/18 (намеренно разный).** Согласие родителя на обработку нужно до 16 лет (`isMinor`); согласие на запись урока — до 18 (`isChild`). Ребёнку 16–17 лет на обработку согласие не нужно, а на запись его урока — нужно. Строже = безопаснее; закреплено тестом `f25-erasure.test.ts`, не менять без решения юриста.
