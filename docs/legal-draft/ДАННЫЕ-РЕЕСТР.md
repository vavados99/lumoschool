Правовая основа везде — **предположение, проверит юрист** (варианты: договор об услуге; согласие родителя; законный интерес для безопасности/журнала; юридическая обязанность по учёту). Статей не указываю — юрист подставит.

## Ручки и тесты
- Экспорт: `GET /api/export/:id` (S 16+ и P — свои/ребёнка; O — только с правом `data.export_any`, по умолчанию его нет — `consent.test.ts:162`; ребёнок до 16 сам — нельзя, `:123`).
- Согласия: `GET/POST /api/consents/:id`, `POST /api/consents/:id/revoke` (`consent.test.ts:30`, `:64`, `:85`).
- **Стирание: HTTP-ручки НЕТ.** Есть только функция `eraseData` (ядро, право `data.erase`/`data.erase_any`), проверена тестами ядра (`consent.test.ts:176`, `:207`, `:219`); из сервера она не вызывается. Просьбу об удалении сейчас выполняет разработчик вручную — см. `ИНЦИДЕНТ-УТЕЧКА-ЧЕРНОВИК.md`, «Канал просьб».
- Чистка: `runRetention` (право `retention.run`, только O) — по таймеру планировщика (`scheduler.ts:105`, умолчание раз в час, `SCHEDULER_CLEANUP_MS`) или `npm run maintenance`; тесты `consent.test.ts:229`, `:247`.
