# Политика видеозаписей уроков (черновик; предложение, не факт)

## Что есть в коде (факт)
- Запись **выключена по умолчанию**: `lessons.recording ... DEFAULT 0` (`db/migrations/002-room.sql`); тест `room.test.ts:258`.
- Включить может **только владелец** (`POST /api/rooms/:id/recording`, право `room.recording.set`); преподаватель → 403.
- Включение возможно, только если у каждого записанного ученика **младше 18** (`isChild`, а не порог 16) есть активное согласие `lesson_recording`; иначе 409 `recording_consent_missing` (`room.ts`; `room.test.ts:258`).
- Допущенные в комнату видят признак «идёт запись» (`recording:true` в состоянии комнаты).
- Кто и когда включил — `lessons.recording_set_by/at` и `audit_log` (`room.recording.on/off`).
- **Видео — заглушка**: `GET /api/rooms/:id/video` → `{provider:'stub', status:'not_connected'}` (`room.test.ts:289`). Провайдера нет, **файлов записей не существует**.
- Ядро не полагается на матрицу прав: даже при лишнем выданном праве без согласия запись не включится (`room.test.ts:303`).

## Чего в коде нет (решают юрист и Влад)
Срока хранения записи; списка, кто смотрит; удаления записи по просьбе; шифрования; страны хранения; экспорта записи; согласия взрослого ученика 18+ (код проверяет согласие только у детей); поведения при отзыве согласия во время идущей записи; правила, если родитель одного ребёнка группы отказал.

## Предложение политики (не факт)
1. **Цель:** только [контроль качества / разбор инцидентов безопасности] — допустимость подтверждает юрист. Не для маркетинга и публикации.
2. **Включает:** только владелец, на конкретный урок. Урок записывается, лишь если согласие есть у всех детей урока.
3. **Согласие:** отдельное `lesson_recording` от родителя (текст — `СОГЛАСИЕ-РОДИТЕЛЯ-ЧЕРНОВИК.md`, блок B); от взрослого ученика — собственное (в коде не реализовано).
4. **Срок хранения (предложение):** [30 дней], затем автоудаление; продление — только при инциденте, решением владельца с записью в журнал. Цифра не из кода, юрист поменяет.
5. **Кто смотрит (предложение):** только владелец, каждый просмотр — в журнал. Преподавателям и родителям записи недоступны (родитель может присутствовать в комнате как наблюдатель, `room.test.ts:54`).
6. **Удаление:** по просьбе родителя запись ребёнка удаляется — механизм делать вместе с провайдером.
7. **Провайдер:** выбор — решение Влада (пункт Д1); нужны договор обработки данных и хостинг в ЕС — юрист.
8. До подключения провайдера и подписи юриста записи **не включаются**; в согласии и политике честно писать «не ведутся».
